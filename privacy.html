Privacy Policy

Last updated: 2026-11-02

TimeTree Sync is a personal tool used only by its owner.

  • Data accessed: events in the owner's own Google Calendar, through the Google Calendar API.
  • Use: only to create, update and delete events in the owner's own Google Calendar so that it matches the owner's TimeTree calendars.
  • Storage: credentials and sync state are stored only on the owner's own computer.
  • Sharing: no data is sold, shared with, or sent to any third party.
  • Google user data is used in accordance with the Google API Services User Data Policy, including the Limited Use requirements.

プライバシーポリシー

  • 取得する情報：所有者本人の Google カレンダーの予定（Google Calendar API 経由）
  • 利用目的：本人の TimeTree カレンダーと一致させるため、本人の Google カレンダーの予定を作成・更新・削除することのみ
  • 保存場所：認証情報と同期状態は所有者本人のPC内にのみ保存
  • 第三者提供：一切の販売・共有・送信を行いません

Contact: please open an issue in this repository.
